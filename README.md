# Kalender-App

Android-App zur Verwaltung der auf dem Gerät gespeicherten Kalendertermine.

## Technologien
- Vue.js
- Ionic
- Capacitor
- TypeScript

## Native Funktionen
- Kalenderzugriff
- Zwischenablage

## Voraussetzungen
- Android-Gerät
- Kalenderberechtigung

## Installation
npm install
npm run build
npx cap sync android
